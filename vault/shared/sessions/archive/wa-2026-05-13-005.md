objective: |
  Extracción bottom-up completa de la espina dorsal descendente desde el bootstrap construido para las 8 capabilities operant del proyecto (CAP-A..G + CAP-J), produciendo los 5 niveles arquitectónicos: Features (Cohn INVEST + Patton) → Stories (Cohn user stories) → Examples (Adzic SbE elicitation) → AC (criterios derivados) → Specs Gherkin formales (Adzic Given/When/Then por AC).

  Excluidas las 2 capabilities planned (CAP-H portabilidad multi-harness, CAP-I adopción retroactiva) — sus piezas no están construidas en el bootstrap.

  Output al cierre: ~30-40 feature files + ~100-150 story files + ~100-150 spec Gherkin files (status: ready-for-implementation) en `vault/product-owner/specs/` + discovery doc reclasificando piezas del bootstrap en 5 niveles + audits de 5 dimensiones (technical, usability, business, security, quality) + report QA de verificabilidad consolidada.
