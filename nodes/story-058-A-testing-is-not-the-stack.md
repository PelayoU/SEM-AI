# Story 058-A — Testing alone <80 %; full DRE stack mandatory

> Parent: [[feature-058-qa-testing-strategy-skill]].

As **QA defending the test strategy against a "testing only" plan**, I want **explicit framing that cumulative testing-alone DRE seldom tops 80 % and that >95 % requires inspections + static analysis + testing combined**, so that **"testing only" is rejected as malpractice for mission-critical work**.

## Conditions of Satisfaction

- Strategy document names the >95 % stack composition.
- Testing-only plans flagged at review.
