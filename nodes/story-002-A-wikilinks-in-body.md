# Story 002-A — Reference related artifacts via `[[id]]` in body

> Parent: [[feature-002-wikilinks-narrative-cross-reference]].

## Cohn statement

As a **node author**, I want **to reference related artifacts via `[[id]]` in body prose**, so that **backlinks and graph view light up automatically without bookkeeping**.

## Conditions of Satisfaction

- Wikilinks target existing nodes (or are explicitly deferred placeholders).
- Backlinks pane populates for every linked node.
