## What it delivers

Lets the PO design / manage user participation across the project lifecycle using Jones BP #12's 12-form inventory (JAD, QFD, focus groups, usability labs, embedded full-time user, defect reporting, acceptance testing, etc.) with scale-aware technique selection and the 10–50 % effort-ratio empirics (avg 20 %, satisfaction risk below 10 %).
