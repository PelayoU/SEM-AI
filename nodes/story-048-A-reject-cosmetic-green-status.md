# Story 048-A — Refuse cosmetic "done" without review artifact

> Parent: [[feature-048-po-milestone-tracking-skill]].

As a **PO running milestone reviews**, I want **to refuse cosmetic "done" status when no review artifact (minutes / defect log / signoff) exists**, so that **the tracking surface stays honest** (per Jones: cosmetic green status is the diagnostic of litigated projects).

## Conditions of Satisfaction

- Milestone marked closed only if review artifact present.
- "Status report without artifact" rejected with reason.
