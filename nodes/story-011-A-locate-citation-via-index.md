# Story 011-A — Locate exact citation point via INDEX

> Parent: [[feature-011-bibliography-index]].

## Cohn statement

As a **skill author authoring or refining a skill**, I want **the bibliography INDEX to surface exact slide / page anchors for each concept**, so that **I cite primary source verbatim without scanning the whole PDF**.

## Conditions of Satisfaction

- `bibliography/INDEX.md` carries per-PDF tables (slide-by-slide / page-by-page).
- Every concept used by a skill has at least one INDEX entry.

## INVEST self-check

✅ I · ✅ N · ✅ V (citation latency near zero) · ✅ E · ✅ S · ✅ T (open INDEX; find any cited concept).
