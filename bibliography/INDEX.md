### A.8. `gherkin-reference.pdf` — Cucumber official docs

| Página | Contenido |
|---|---|
| 1 | **Gherkin keywords primary**: Feature · Rule (v6+) · Example/Scenario · Given/When/Then/And/But · Background · Scenario Outline / Scenario Template · Examples / Scenarios |
| 1 | **Secondary**: `"""` Doc Strings · `|` Data Tables · `@` Tags · `#` Comments |
| 1 | Comments: # at start of line. 2 spaces indentation recommended. |
| 2 | **Feature**: high-level description + groups related scenarios. First primary keyword. Free-form description text. |
| 2 | **Rule** (Gherkin v6+): represents one business rule. Groups scenarios belonging to a rule. |
| 3 | **Example/Scenario** (synonyms): concrete example illustrating business rule. Recommended **3-5 steps per example**. Initial context (Given) / event (When) / outcome (Then) |
| 3-4 | **Steps**: Given/When/Then/And/But or `*` |
| 3 | **Given**: initial context — typically something that happened in the past |
| 4 | **When**: event or action — person interacting with system or event triggered |
| 4 | **Then**: expected outcome — assertion comparing actual vs expected. **Observable** output |
| 4 | And, But: chain successive Given's or Then's |
| 5 | `*`: asterisk in place of normal keywords for list-of-things readability |
| 5-6 | **Background**: repeated Given steps. Run before EACH scenario. Tips: don't use for complicated states, max 4 lines, vivid names, keep scenarios short |
| 7 | **Scenario Outline / Template**: same Scenario multiple times with `<>`-delimited parameters |
| 7 | **Examples** section: one or more required by Scenario Outline. Run once per row |
| 8 | **Step Arguments**: Doc Strings (triple `"""` or backticks, optional content type) · Data Tables (`|` pipe-delimited) |
| 8 | Data Table escaping: `\n` newline, `\|` pipe, `\\` backslash |
| 9 | **Spoken Languages**: `# language: <code>` header. Default English. |
